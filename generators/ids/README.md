# ids

The confref identifiers of conference series and events (decisions 0005, 0013–0016; kg-commons 0022). Read the
docstring of `generate.py`: the groups, the identifiers and their history, the facts. `format_id` and `parse_id` are
the form of an identifier (type letter, base32, check character). The first version has no previous version; every
later run compares with the stable version of `ids`.
